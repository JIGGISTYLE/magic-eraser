# EraseAI official logo

The approved artwork is `eraseai-original.png`, copied byte-for-byte from the user-supplied image.
SHA-256: `b42d4cd3c03eb57677fe6c5e8c4f1d1339f19277a27e6584310828d4efc07a1b`.

`eraseai-logo.svg` embeds a lossless crop of the exact original wordmark and symbol without repainting or regenerating it.
`eraseai-icon.svg` frames the same eraser/E symbol for browser icons and API documentation.
Both SVGs embed only their visible original pixels, so they work without external image requests. Keep the ivory lettering,
black background, violet accent, and original proportions. Main headers and browser icons use the symbol only. Sidebar headers use the full lockup.

The previous green E and Magic Eraser graphics are retired. Original upstream author credits in README remain attribution, not current branding.
